# Code of Conduct

The Code of Conduct is intentionally written in simple language. For any clarification, please contact the core team.

---

## Not Allowed

- Terrorism
- Child Porn
- Illegal Activities
- Fighting with CEO physically and verbally

---

## Allowed
 
- Criticism and Condemnation 
- Disagreements and Debates
- Roasting and Sarcasm
- Slangs

---

## Scope

This Code of Conduct applies to the xLaDe project everywhere, including both offline and online workspaces.
Any discussion or conversation involving xLaDe will automatically inherit it.

---

## Enforcement

The CEO will have full rights to ban any member of community.
The CEO's decision will be final.

---

## Note

Common sense prevails.
Please don't do anything stupid.
Community members can request for any change in the Code of Conduct.
