# xLaDe Security Advisories

This directory contains public security advisories for xLaDe.

`DCVE` identifiers are xLaDe-local disclosure identifiers. They are **not**
CVE IDs assigned by the CVE Program.

## Advisories

| Identifier | Severity | Summary |
|---|---|---|
| [DCVE-2026-0001-xLaDe](DCVE-2026-0001-xLaDe.txt) | High | A feature-branch push could replace SourceForge `main`. |
| [DCVE-2026-0002-xLaDe](DCVE-2026-0002-xLaDe.txt) | High | Mirror credentials could be used by same-repository feature-branch workflows. |
| [DCVE-2026-0003-xLaDe](DCVE-2026-0003-xLaDe.txt) | High | Kernel protection could pass when its baseline was unavailable and miss submodule changes. |
